# Nicotine-Cooldown

Android-приложение с **двумя дневными окнами** для фиксации приёма никотинзаменителя (утро / вечер по системному времени).

## Основное

- **Таймер и кольцо прогресса** — сколько осталось до открытия следующего окна или до его закрытия, пока окно активно.
- **Подтверждение приёма** — одна отметка на слот в день; после нажатия окно считается использованным.
- **Индикаторы слотов** — наглядно, какое окно сейчас, что уже отмечено сегодня.
- **Защита от отката системных часов** — при подозрительном изменении времени приём блокируется.
- **Локальное хранение** — данные в DataStore на устройстве, без аккаунта.
